# 포스트모템 — 가상 사건: 잘못된 결측치 처리 (Issue #2)

## 사건 개요
- 증상: 파이프라인이 결측치 전략을 일관되게 적용하지 않아 평균/분산이 왜곡됨

## STAR
- Situation: 초기 `dropna()` 기본값이 무음으로 데이터를 삭제
- Task: 통계 결과 신뢰성 복구 및 재발 방지
- Action: 결측치 strategy 명시화, 처리 메타데이터 반환, golden dataset 회귀 테스트 추가
- Result: v0.1.1 패치, 결측 처리 이력 추적 가능

## Root Cause
- 결측치 전략 기본값이 암묵적이었고 테스트 부족

## 예방 조치
- 필수 strategy 파라미터화
- 정제 전/후 shape·결측 수 로그
- EDA 리포트에 결측치 리포트 포함
- CI에 데이터 품질 테스트 추가
